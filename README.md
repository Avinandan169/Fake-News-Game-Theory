# Fake News Propagation and Platform Moderation

A beginner-friendly Python project that combines a small game-theory model with a fake-news propagation simulation. It uses only Python, NumPy, and Matplotlib—no GUI, database, or machine learning.

> The simulation is a classroom illustration. Its results are generated by the model's assumptions and are not real-world statistics.

## What the program does

1. Displays a payoff matrix for a content creator and a social-media platform.
2. Calculates the mixed-strategy Nash equilibrium.
3. Asks for simulation values in the terminal, with safe defaults.
4. Runs **no**, **moderate**, and **strict** moderation using the same population, initial exposure, number of rounds, sharing probability, and random seed.
5. Reports final exposure, percentage of the population, and reduction compared with no moderation.
6. Saves two graphs: `propagation_over_time.png` and `final_exposure_comparison.png`.

## Installation

```bash
python -m pip install numpy matplotlib
```

## Run the project

```bash
python main.py
```

Press Enter at each prompt to use the defaults:

- Population: 1,000
- Initially exposed users: 10
- Rounds: 12
- Base sharing probability: 35%
- Random seed: 42

Using the same seed makes a run repeatable. Changing it creates a different illustrative run while keeping the same model.

To run without saving graphs:

```bash
python main.py --no-graphs
```

## Run tests

```bash
python main.py --test
```

or:

```bash
python -m unittest discover -s tests -v
```

Read `TESTING.md` for the list of checks and expected behaviour.

## Model assumptions

- A newly exposed user gets one chance to share in the following round.
- A sharing user exposes five contacts on average.
- Moderate moderation reduces the base sharing probability to 35% of its original value.
- Strict moderation reduces it to 10% of its original value.
- Exposure cannot exceed the entered population.

The game-theory model and propagation simulation are related to the same topic, but the equilibrium probabilities are **not** used as simulation inputs.
